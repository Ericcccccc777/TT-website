What you need for TMI v0.3.0

  • A Mac (Apple silicon or Intel) or a Windows PC.
  • To track token usage, use Claude Code, Codex or Kimi Code on this computer. Installing the app itself doesn’t require a command-line tool.
  • To chat with cLAudE or CodeX, sign in to the corresponding CLI using your own Claude or ChatGPT plan. For BlueGiantFish, enter your DeepSeek API key.

Getting started with TMI v0.3.0

  1. In the first-run guide, pick your main character: cLAudE, CodeX or BlueGiantFish.
  2. For chat, open Settings → Cast, choose your companion and check Chat connection.
  3. To join the leaderboard: Settings → Leaderboard.
  4. WeChat, reaching out, time of her own: turn them on one by one in Settings. They all start off.

Opening it the first time on macOS

  1. Open the downloaded dmg and drag the app into Applications.
  2. Open it from Applications. macOS will say it can't verify the app: it isn't signed with a paid Apple certificate, so this is expected. Click Done, not Move to Trash.
  3. Open System Settings → Privacy & Security, scroll down to Security, click Open Anyway next to the blocked app, authenticate, and confirm.
  4. From then on it opens like any other app. You only do this once.

Windows

  1. Extract the whole zip first (right-click → Extract All), then run the exe inside the extracted folder.
  2. If SmartScreen stops it, click More info → Run anyway.

Make sure it's the real thing

Every release comes with a SHA256SUMS file. Don't install a copy you got anywhere other than the releases page.
