使用 TMI v0.3.0 需要什么

  • 一台 Mac（Apple 芯片和 Intel 都能用）或 Windows 电脑。
  • 想记录 Token 用量，可以在这台电脑上使用 Claude Code、Codex 或 Kimi Code。单独安装 App 无需命令行工具。
  • 和 cLAudE 或 CodeX 聊天，用自己的 Claude 或 ChatGPT 订阅登录对应的命令行。和大肥鱼聊天，填入自己的 DeepSeek API 密钥。

TMI v0.3.0 首次使用指南

  1. 首次引导里选一位当主角色：cLAudE、CodeX 或大肥鱼。
  2. 打开「设置 → 她们」，选中想聊天的角色，在「聊天连接」里查看连接状态。
  3. 想上排行榜：设置 → 排行榜。
  4. 想连微信、让她主动找你、让她自己出去逛：设置里一样一样打开，默认都关着。

macOS 第一次打开

  1. 打开下载的 dmg，把 App 拖进「应用程序」文件夹。
  2. 从「应用程序」里打开。会提示「无法验证」：App 没有买苹果的签名，这一步正常。点「完成」，别点「移到废纸篓」。
  3. 打开「系统设置 → 隐私与安全性」，往下翻到「安全性」，在被阻止的那一行旁边点「仍要打开」，验证身份，再确认一次。
  4. 之后就跟别的 App 一样了，只需要这一次。

Windows

  1. 先把 zip 完整解压（右键 → 全部解压），再进解压出来的文件夹运行里面的 exe。
  2. SmartScreen 拦的话，点「更多信息 → 仍要运行」。
