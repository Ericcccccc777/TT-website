常见问题

她会看我的代码吗？
记账用的是本机的用量记录，其中包括 Token 数和模型名，无需读取源代码。给 cLAudE 打开「看你的文件」后，她也能读取桌面、文稿和下载文件夹里的文件。各项功能使用哪些数据，可以查看隐私说明。
跟她聊天花谁的钱？
花你自己的。cLAudE 用你电脑上的 claude 命令行和你的 Claude 订阅，CodeX 用 codex 和你的 ChatGPT 订阅，大肥鱼用你填的 DeepSeek key。App 不碰你的登录和密码。
她自己逛网页、画画，会不会一直烧额度？
这几样默认关。打开以后，她自己玩的时候用便宜的小模型（Haiku、gpt-6-luna），多久出去一次你来填。设置 →「用量」里能看到 App 自己花了多少。
排行榜上传什么？
排行榜默认关闭。开启后会同步昵称和累计用量，你也可以填写地区、展示项目。公开榜单会显示记录创建和最后更新的时间。隐私说明列出了全部上传字段，以及其中哪些会公开。
以前的树呢？
上一代是种树的那版。树和地图都拿掉了，换成住在右下角的 AI 小人；排行榜还是那一个，分数接着算。
为什么叫 cLAudE、CodeX？跟 Anthropic、OpenAI 有关系吗？
没有关系。她们是粉丝向的角色，名字故意改了大小写；Claude、Codex 等名字是各自公司的商标。
能换一位坐在桌上吗？
能。设置里随时换主角色。另外三位（小月、智狐、哈基米）还在定稿，只在你用 Kimi、GLM、Gemini 的时候来串门。
macOS 提示无法验证开发者？
App 没有买苹果的签名。去「系统设置 → 隐私与安全性」点「仍要打开」就行，只需要一次。
小屋要花真钱吗？
不花。房子、吃的、书都拿你用掉的 token 买，那是 App 里记的数，不是钱。
她会一直弹窗打扰我吗？
不会。她不弹系统通知；找你的时候在屏幕右上角冒一张我们自己的小条，停上去不收，点叉收起。设置里能关。
数据存在哪？能删吗？
macOS 在 ~/Library/Application Support/TokenForest/，Windows 在 %APPDATA%\TokenForest\。她的记忆、聊天记录在设置里能一键清空；排行榜那一行可以申请删除。
收费吗？
现在免费。
