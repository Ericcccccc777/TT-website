TMI 隐私声明(中文)

版本: 1.1-beta(发布前草案) · 最后更新: 2026-10-25 · 生效: 首个公开版本发布时 发布者: Poietic Studio

TMI(Token-Made Intelligence)是一个桌面应用:几个动漫风格的小角色(每家 AI 一个)坐在屏幕角落,跟着你电脑上的 AI 编程工具做动作,并替你记下这些工具用掉的 token。本声明说明 App 读取什么、保存什么,以及——仅在你主动开启后——上传什么。同一文本发布于官网与本仓库;本文件的 git 历史即隐私声明的公开变更记录。

摘要

  • 核心功能在你的设备上运行:无需账号、无需 API key、无需网络。
  • App 没有遥测、广告和崩溃上报。
  • 它读取的是 AI 编程工具已经写在你本机的日志和状态文件,从不读取你的源代码文件(除非你在链接微信里给克劳德打开「看你的文件」,她就能读你的桌面、文稿、下载,见「链接微信」)。
  • 不保存、不上传 AI 编程工具里的 prompt、AI 回复或命令内容。(微信里跟她们聊的话,开着「记住聊过的事」时存在本机,见「链接微信」,不上传给我们。)
  • 会联网的可选功能默认全部关闭。会联网的可选功能是:排行榜(含项目展示)、价格表更新、更新检查(含安装包下载)、链接微信、她的小屋里的斗地主、小游戏、一起看和平时说话、每日漫画成品接收。只有排行榜会上传内容;开启前会列出全部字段,关闭时会请求删除你的记录。
  • 我们不出售个人数据。

App 在本地读取什么

记账用的(用量会计入):

Claude Code:  ~/.claude/projects/**/*.jsonl
OpenAI Codex: ~/.codex/sessions/**/rollout-*.jsonl
Kimi Code:    ~/.kimi-code/sessions/**/wire.jsonl

只用来判断「这家 AI 此刻在不在干活」的(用量不计入、不上传):

Gemini CLI:             ~/.gemini/tmp/<项目>/chats/*.jsonl(macOS 沙箱里是 ~/.cache/.gemini/tmp/…)
ZCode:                  ~/.zcode/cli/db/db.sqlite、~/.zcode-beta/cli/db/db.sqlite,只读打开
DeepSeek Harness(dsh):  ~/.dsh/sessions/**/session*.jsonl[.zstd]

相应工具自定义目录时，App 也会按 CLAUDE_CONFIG_DIR、CODEX_HOME 和 DSH_HOME 查找。角色从近期会话恢复动作。首次使用时，用量从日志末尾开始计。下次启动能恢复读取位置时，会从那里接着记。数据面板由单独的只读进程在本机读取三个记账来源的全部历史。它也会在启动约 3 分钟后和之后每 6 小时在后台重扫。

从记账日志里,App 使用 token 数量、时间戳、模型名、会话标识、工作目录、Git 分支、AI 生成的会话标题、日志路径和消息类型。为了让角色换动作，App 每秒只在内存里查看近期活动，包括工具名、命令行工具执行的命令（用来分辨测试、提交、装包、构建和翻文件）、回合边界和工具报错。Claude Code 的请求按会话跟踪，工具调用、进度和结果按编号配对。启动时可以从近期会话的末尾恢复动作，每个会话最多回看 8 MiB。ZCode 只跑三条只读查询(有没有在跑的回合、什么工具、什么模型),不碰对话内容;压缩过的 DeepSeek Harness 日志只看文件修改时间。

解析日志时,整行内容(可能含 prompt 或命令)会经过内存。App 从不把这些日志里的 prompt、回复或命令写进自己的文件,也从不上传。

数据目录:macOS 是 ~/Library/Application Support/TokenForest/,Windows 是 %APPDATA%\TokenForest\。目录名里的 TokenForest 是旧名,暂时沿用。

网络行为

所有可选功能都关着时(这是默认状态),App 不发出任何出站请求。两条已公开的非出站行为:未完成的排行榜删除会在每次启动时重试,直到确认;在 macOS 上,打开托盘菜单或设置窗开着时,App 会连一下本机回环地址 127.0.0.1:18011/health,看有没有 WeClaw 在跑。
