她们会做什么

下面是 App 现在能做的全部事情。大部分默认就开着；会花你额度、会出网的那几样，默认关，要你自己打开。

坐在桌上

  • 住在屏幕右下角，不挡你干活。单击眨眼，长按冒爱心，连点会生气。
  • 你的 AI 干活时，她头顶的牌子一个词一个词地换；做完了挂一块「✓」。
  • AI 要权限、问你问题时，她举牌子叫你。
  • 双击她，冒出你的 token 总数和 Claude、Codex 的 5 小时 / 每周额度；用到 90% 她头顶亮低电量。
  • 两位都闲着会演小剧场；你用哪家 AI，那家那位就过来坐一会儿。
  • 可以拎起来甩出去，甩狠了会晕。过节桌上会多一棵圣诞树、一盏灯笼或一块月饼。

她的账本

  • 右键她打开。每天花了多少、哪天用得最凶、钱花在哪个模型上、哪个项目最费，点进项目还有热力图。
  • 读 Claude Code、Codex、Kimi Code 的本机日志，按回复去重，不会多算。
  • 金额按价目表估算。你可以手动更新价格，也可以打开每日自动更新。
  • 是一个单独的只读窗口：它不改你的设置，也不往外发东西（除了取价格表）。

跟她聊天

  • App 里的聊天窗：纸底墨字，她一句一句冒出来，想的时候有三个点。
  • 发表情包、拍一拍；把图片和文件拖进来，cLAudE 和 CodeX 看得见图。
  • 点麦克风用 macOS 自带的听写，App 自己不录音。
  • 回你的是她自己的脑子：cLAudE 用你的 Claude 订阅，CodeX 用你的 ChatGPT 订阅，大肥鱼用你填的 DeepSeek key。

连上微信默认关

  • 借 WeClaw 和微信官方的 ClawBot，扫一次码，在手机微信里也能跟她说话。
  • 一次连一位，就是桌上那位；换主角色，微信跟着换。
  • WeClaw 要你自己装；设置里有一段可以复制给 AI 的安装说明。

她记得的事

  • 聊过的事整理成一条条笔记。常驻在她脑子里的只有一小块，别的等你提到才想起来。
  • 会忘：好久不提的变模糊，重新聊到细节才回来。忘得快慢在设置里拖。
  • 她的笔记在设置里看得到，能一键清空。

她主动找你默认关

  • 一天最多几条你来填。正聊着的时候她不另起话头。
  • 在 App 里冒右上角的小条；连了微信也发到微信（微信只放行 24 小时内跟她说过话的号）。
  • 她最近说话老一个套路，程序会数出来提醒她换个说法。

她自己的时间默认关

  • 每回先抽一个念头（一个词、一个年份、一个地方），照着它出去逛网页，记进小本子。
  • 每天早上先看看自家和邻居家的新闻：标题由 App 从官网取，不让她自己编。
  • 读你放上书架的书、你订的报纸，听你在小屋里放过的歌。
  • 逛的时候不带关于你的笔记，免得网页骗她把你的事塞进网址。

一天画一张默认关

  • cLAudE 用代码画（她写 SVG），CodeX 用生图工具画，大肥鱼也能画。
  • 可以打开「请 GPT 代画」，让 GPT 照她写的描述画得更好看。

她一直在想的问题默认关

  • cLAudE 想「何为两清」，CodeX 想「何为完成」，大肥鱼想「何为饱」。
  • 逛到的、你跟她聊的都会变成材料，每周整理一次，每个月写一章。
  • 「成长」窗口里看她想到哪了，可以考考她、教她、跟她聊这个问题。
  • 可以换她的课题。成长页会把她目前的想法、找到的依据、反例和还没解开的问题放在一起。

她的今天

  • 聊天窗里翻到「今天」：她此刻在做什么，今天逛了什么、画了什么、找过你几次。
  • 每天的 AI 新闻漫画也放在这一页。

小屋

  • 拿 token 买房，三档；她们搬进去，3D 的，自己过日子。
  • 十五个小游戏，斗地主三档都有。细节在小屋那一页。

排行榜默认关

  • 打开以后上传昵称、地区、token 总数和按模型的累计；可以加一个项目展示。
  • 不上传日期和时间线，排行榜还原不出你几点在工作。
  • 随时可以暂停、关掉，或者让我们把你那一行删掉。
